# Excel Sales Analysis — Day 1

## Project Overview

This is a beginner-level Excel data analysis project created as part of my Excel learning journey.

## Dataset

The dataset contains sales transactions with:

- Order ID
- Product
- Region
- Sales
- Profit
- Order Date

## Excel Skills Used

- Basic Excel formulas
- SUM
- AVERAGE
- MIN
- MAX
- COUNT
- Cell formatting
- Currency formatting
- Date formatting
- Conditional formatting
- Sorting
- Filtering
- Excel Tables

## Analysis Performed

- Calculated total sales
- Calculated average sales
- Identified highest and lowest sales
- Calculated total and average profit
- Analyzed orders by region
- Analyzed laptop sales
- Applied conditional formatting
- Sorted sales from highest to lowest

## Learning Outcome

This project helped me practice the fundamentals of Excel data handling and basic analysis.
